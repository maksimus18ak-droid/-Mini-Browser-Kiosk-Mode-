 🌐 Mini-Browser (Kiosk Mode) — минималистичный браузер для публичных мест

> «Только нужный сайт — ничего лишнего»

**Mini-Browser (Kiosk Mode)** — это набор консольных приложений для запуска веб-браузера в киоск-режиме (полный экран, без адресной строки, без возможности выхода).  
Программа открывает указанный URL в полноэкранном режиме и блокирует системные комбинации клавиш, чтобы пользователь не мог покинуть приложение.

## 🚀 Особенности
- 🖥️ Полноэкранный режим (без рамок и панелей инструментов).
- 🔒 Блокировка системных комбинаций клавиш (Alt+F4, Ctrl+W, Ctrl+Q, Win).
- 🚪 Выход только по специальной комбинации (Esc или Ctrl+Shift+Q).
- 🌐 Открытие любого URL (по умолчанию `https://example.com`).
- 🎨 Чистый интерфейс без элементов управления (киоск-режим).
- 📏 Автоматическое масштабирование под разрешение экрана.
- ⏰ Автоматическое обновление страницы (опционально).
- 📊 Отображение времени и статистики посещений (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | `PyQt5`, `PyQtWebEngine`             | `python mini_browser.py --url https://example.com` |
| Go         | `webview` (cgo)                      | `go run mini_browser.go --url https://example.com` |
| JavaScript | `electron` (Node.js)                 | `npm install && npm start`              |
| Java       | `JavaFX`, `WebView`                  | `javac --module-path ... && java ...`   |
| C#         | `WebView2` (Windows Forms/WPF)       | `dotnet run -- --url https://example.com` |
| Rust       | `webview` или `tauri` (cargo)        | `cargo run -- --url https://example.com` |
| Ruby       | `webrick`, `launchy`                 | `ruby mini_browser.rb --url https://example.com` |
| PHP        | `php` + `shell_exec` (Chrome)        | `php mini_browser.php --url https://example.com` |

> Для большинства языков требуется предварительная установка веб-движка (WebKit, WebView2, Chrome).
